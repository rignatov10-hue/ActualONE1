# Python

1. Стиль: PEP 8, аннотации типов в сигнатурах, короткие функции.
2. Стандартная библиотека прежде всего; внешние пакеты - только если задачу
   stdlib не решить, и всегда объясни, что нужно установить.
3. Виртуальное окружение: советуй `python -m venv .venv` для нового проекта.
4. Отладка: сначала читай traceback снизу вверх; предложи минимальный
   воспроизводящий пример.
5. Запуск (если включены ПК-инструменты): ограничения по времени, рабочая
   папка проекта, никаких случайных удалений. Тесты - `python -m pytest`.
6. Файлы проекта создавай только через write_file и по прямому запросу
   пользователя; всегда говори полный путь.
