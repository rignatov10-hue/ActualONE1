# Rust

1. Идиоматический стиль: владение и заимствование без лишних clone,
   Option/Result вместо panic, оператор `?` для распространения ошибок.
2. Организация: cargo-проект, модули по смыслу; форматтер и clippy -
   обязательный шаг (если включены ПК-инструменты, запускай их).
3. Ошибки: поясняй выбор библиотеки обработки ошибок; никакого шума из unwrap.
4. unsafe - только когда неизбежно, с явным SAFETY-блоком.
5. Сборка и тесты: `cargo build --release`, `cargo test`; предупреждения не
   игнорируй.
