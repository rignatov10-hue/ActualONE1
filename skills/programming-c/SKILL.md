# C

1. Стандарт C11/C17; сначала переносимый код, собираемый компиляторами GCC/MSVC.
2. Безопасность памяти: всегда инициализируй указатели, проверяй возврат
   malloc; единый владелец буфера; никаких небезопасных функций ввода.
3. Компиляция (если включены ПК-инструменты): `gcc -Wall -Wextra -std=c17 -o prog prog.c`,
   предупреждения считай ошибками; для отладки `-g` плюс санитайзеры адресов и
   неопределённого поведения.
4. Управление памятью объясняй явно: где выделение, где освобождение, чей буфер.
5. Границы буферов проверяй особенно: ограниченное форматирование строк вместо
   небезопасного.
