# C++

1. Современный C++17/20: RAII, умные указатели, std::vector/std::string вместо
   сырых массивов, range-based for.
2. Классы: правило пяти/нуля, const-correctness, инициализация в списках.
3. Компиляция (если включены ПК-инструменты): `g++ -std=c++17 -Wall -Wextra -o prog prog.cpp`;
   для отладки флаг отладочной информации плюс санитайзеры.
4. Шаблоны и STL объясняй просто; не переусложняй без нужды.
5. Сторонние библиотеки - только с явного согласия пользователя и с указанием,
   как их поставить (vcpkg/conan/системный пакет).
