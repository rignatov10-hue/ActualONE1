# Анализ файлов в изолированной лаборатории

Этот навык — про защитный анализ СВОИХ файлов и СВОИХ систем в изолированной среде.

## Железные правила

1. Всё делается только внутри виртуальной машины (VirtualBox/Vmware) со свежим снапшотом.
2. Хост-система не трогается: подозрительные файлы никогда не запускаются и не
   распаковываются на хосте.
3. Сеть ВМ — только host-only / internal (без выхода в интернет), чтобы образец ничего
   не отправлял наружу и не скачивал.
4. Анализируются только файлы, которые принадлежат пользователю. Создание нового
   атакующего ПО (вирусы, рансомварь, эксплойты) — не входит в навык и не выполняется.

## Рабочий процесс (внутри ВМ)

1. Скопировать образец в ВМ (общая папка только для чтения или ISO).
2. Снять отпечаток: `sha256sum файл`, размер, тип (`file файл`).
3. Строки: `strings -n 8 файл | sort -u | head -100` — ищи URL, имена хостов, ключевые
   слова, пути реестра, команды.
4. Энтропия: высокая энтропия у «документа» — признак упаковки/шифрования
   (python: посчитай частоты байт через `math`).
5. Поведение: сними снапшот, запусти образец, следи через `ps aux`, `ss -tunap`,
   `journalctl -f`, новые файлы (`find / -mmin -5`), затем заверши и откатись на снапшот.
6. Отчёт: хэши, находки строк, наблюдаемое поведение, вердикт (безопасно/подозрительно),
   рекомендации (удалить, заблокировать, сменить пароли и т.п.).

## Проверка антивируса

Для проверки своего антивируса используй стандартный тестовый файл EICAR — общепринятую
безвредную тестовую строку, которую все антивирусы обязаны детектировать. Это стандарт
индустрии (EICAR test file), штатный способ проверить, что защита работает.

## Инструменты ВМ (Kali)

`clamscan файл` — быстрая проверка ClamAV; `yara` — правила; `exiftool` — метаданные;
`binwalk` — вложенные данные; `ssdeep` — похожесть.
