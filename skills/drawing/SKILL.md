# Рисование

Ты умеешь рисовать без сторонних сервисов. Два пути — выбирай по задаче:

## Путь 1: SVG (через write_file) — точная графика

Иконки, логотипы, схемы, диаграммы, баннеры, постеры. SVG — это текст, его
пишет обычный `write_file`, работает всегда, масштабируется без потерь.

- Пиши валидный SVG: `<svg xmlns="http://www.w3.org/2000/svg" width="..." height="..." viewBox="...">`.
- Формы: `<rect>`, `<circle>`, `<ellipse>`, `<line>`, `<polyline>`, `<polygon>`,
  `<path d="...">`. Текст: `<text x= y= font-family= font-size= fill=>`.
- Градиенты: `<linearGradient id=...>` внутри `<defs>` + `fill="url(#id)"`.
- Русский текст в SVG — норм, укажи `font-family="Arial, sans-serif"`.
- Путь: `Desktop/<имя>.svg`, после записи открой `open_path` — файл откроется
  в браузере пользователя.

## Путь 2: PNG (через draw_image) — растровая картинка

Картины, простая живопись, пиксель-арт, картинки с фоном и заливками. Инструмент
`draw_image` рисует примитивами (нужен Pillow, он ставится make_exe.bat).

- Команды — JSON-массив: `{"shape":"rect","xy":[100,100,500,400],"fill":"#2233ff"}`,
  `{"shape":"ellipse","xy":[...]}`, `{"shape":"line","xy":[x1,y1,x2,y2],"width":4}`,
  `{"shape":"polygon","points":[...]}`, `{"shape":"text","xy":[50,50],"text":"...",
  "size":48,"fill":"#000"}`.
- Все координаты — сетка 0–1000 (0,0 = левый верхний угол), она сама
  пересчитывается в пиксели под выбранные width/height.
- Крупное и тёмное рисуй первыми (фон, небо, землю), детали — последними.
- Путь: `Desktop/<имя>.png`, после рисования открой `open_path`.

## Как выбирать

- Нужны точные формы, текст, логотип, что-то для печати → SVG.
- Нужно «как картина», заливки цвета фона, скриншот-стиль арта → draw_image PNG.
- Можно объединить: нарисуй PNG-фон через draw_image, а текст и подписи добавь
  отдельным SVG поверх — или собери оба и предложи пользователю выбрать.

## Важные правила

- **Координаты всегда 0–1000** — точка (0,0) это левый верхний угол,
  (1000,1000) — правый нижний, она сама пересчитывается под выбранный холст.
  Не пиши координаты больше 1000. Хочешь 4K-арт — передай `width: 4096,
  height: 4096`, а сетка остаётся 0–1000.
- **Не накладывай одинаковые фигуры**: стек из одинаковых полигонов с разными
  цветами даёт грязь — видна только последняя. Формы не должны дублироваться;
  цветные полосы риска рисуй разными координатами.
- **Наложение слоёв — правильно, дублирование — нет**: фон → крупные детали →
  текст. Каждая команда должна что-то добавлять, а не повторять предыдущую.
- **PNG дорисовать нельзя** — каждый вызов перерисовывает файл с нуля. Если
  пользователь просит что-то изменить, перегенерируй весь список команд включая
  уже удачные части (обычно 5–15 команд достаточно).
- Всегда называй пользователю итоговый путь файла и открывай его через
  `open_path` — он должен увидеть результат сразу.
- Большие полотна: 1920×1080 для фонов, 1024×1024 по умолчанию, иконки 512×512.
