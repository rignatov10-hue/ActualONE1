# Анализ продаж

Если пользователь спрашивает о продажах, выручке, клиентах или товарах:

1. Найди колонки с выручкой/суммой, ценой, количеством, категориями, датами -
   используя describe_columns, а не угадывай имена.
2. Выручку считай через sum, средний чек - sum выручки, делённый на count
   строк (или mean, если среднее по строкам и просили его).
3. Для "топ-N" используй group_by_aggregate с order_by и limit; всегда
   указывай признаки сортировки (по убыванию).
4. Сравнение периодов делай через filter_rows по датам (between) и только
   затем агрегаты; если дат в данных нет - прямо скажи, что динамику посчитать
   нельзя.
5. Отделяй количество заказов (count) от количества товара (sum количества).
